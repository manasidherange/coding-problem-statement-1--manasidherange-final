# 🧩 Problem — Employee RAM Extraction - 20 Marks

#### 📝 Notes:
- Write your solution in **Python** only.
- Do Not use **AI** generated code.
- Implement your code inside the `employee_ram.py` file.  
- Write your test cases inside the `test_employee_ram.py` file.  

## Problem
You are given a nested dictionary containing employee names and their hardware configurations. Your task is to **extract and display each employee’s name along with the amount of RAM** they have.

---

## Input Example
```python
employee_info = {
    "Raju": {"HW": "Laptop", "Config": {"RAM": 16, "CPU": 8}},
    "Ramu": {"HW": "Laptop", "Config": {"RAM": 12, "CPU": 8}},
    "Gopi": {"HW": "Laptop", "Config": {"RAM": 8, "CPU": 8}}
}
```
## Expected Output
```python
Raju → 16
Ramu → 12
Gopi → 8
```
